# Test data

## `identify_corpus.jsonl`

Real identification strings (`sysObjectID`, `sysDescr`, chassis model, presence of the
Printer-MIB / UPS-MIB) of about 270 devices of many vendors, used to test that the device-type
classifier never guesses.

* `truth` is what the device really is, decided by us from the product name and documentation.
* `expect` is what snowth_my_net must output: the true type, or an empty string when there is no
  sure evidence. The corpus holds at least as many "must stay empty" cases as typed ones.
* The test also checks the invariant that a non-empty type always equals `truth`.

Provenance: these strings are emitted by the devices themselves (firmware banners and registered
product identifiers). They were collected from public SNMP recordings in the LibreNMS project
(GPL-3.0); `source` names the recording they came from. No file or other content of LibreNMS
(recordings, OS definitions, type labels) is included in this repository.

## Synthetic fixtures

`tests/fixtures/snmprec/*` are generated by `tests/fixtures/build_snmprec.py` from invented
values only (RFC 7042 documentation MAC addresses, RFC 5737 documentation IP ranges).
